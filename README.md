# Spelunky Classic HD -- C99 port (packaged sources)

Standalone sources of the C99 port of Spelunky Classic HD: the transpiled game, the
runtime, the SDL2 host, and the game's assets and datafiles. Nothing here needs to be
transpiled; just build and run.

Generated by `tools/package_src.py` (source revision `477ddd8`, project
`SpelunkyClassicHD`). Don't edit these files; regenerate the package instead.

## Requirements

- A C99 compiler, [Meson](https://mesonbuild.com) (>= 0.56) and Ninja
- sdl2, SDL2_image, SDL2_ttf, SDL2_mixer (development packages, found via pkg-config)

## Build & Run

```sh
meson setup builddir
meson compile -C builddir
./builddir/spelunky
```

`meson test -C builddir` boots the game headlessly to the title screen.

The executable reads sprites and sounds from `assets/` and uses `data/` as the game's
working directory (settings, `keys.json` and saves are written there). Both default to
the absolute paths of this directory at configure time. Override them with
`--assets DIR` / `--data DIR` at run time, or with
`meson setup builddir -Dassets_dir=... -Ddata_dir=...`.

Other options: `--frames N`, `--screenshot FILE.bmp`, `--press F:VK[:N]`, `--mute`,
`--item OBJECT`.
